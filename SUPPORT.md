# Support

gatedtrain is a prototype maintained on a best-effort basis; there is no support commitment.

- Questions and bug reports: open an issue in the relevant repository (the framework `gatedtrain`, the design set
  `gatedtrain-design`, or a `gatedtrain-recipe-*` repository). Include the commit, the command, and the full error.
- Security issues: see `SECURITY.md`.
